# Cosmetic icons

Drop one square PNG per item into the folder that matches its tab. The app
loads `/icons/<folder>/<id>.png`; until a file exists the button shows its
built-in emoji/letter instead, so nothing breaks.

- **Format:** PNG with transparency, square, 256×256 (512×512 also fine)
- **Name:** exactly the save id + `.png` (case-sensitive)
- **Folder:** one of `frames/`, `styles/`, `badges/`, `titles/`, `pets/`
